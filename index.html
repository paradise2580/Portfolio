RagGen

Brand-grounded ads from real product photos

Live demo Code

The problem

AI-generated ads drift away from the brand: wrong claims, wrong tone, rules ignored. And nobody can tell afterwards what the model was working from.

What I built

A full-stack TypeScript app (React front end, Next.js API, PostgreSQL via Prisma) that turns product photos into catalogue images and short video ads, grounded in the brand's own documents.

Engineering highlights

Generation runs as a durable state machine: each step is idempotent and persisted, jobs are claimed with a lease so two workers never run the same one, and a failed job refunds its credits exactly once. Accounts use hashed sessions and owner/editor roles, and each workspace's data is isolated. Retrieval is a single SQL query that filters by permissions before ranking, fusing keyword and vector search, and every output records which passages it used.

Sentrix

Delivery-risk intelligence for an e-commerce marketplace

Live dashboard API Code

The problem

An operations team can chase about a hundred sellers a week out of three thousand. Late deliveries only show up once the refund and the bad review have already happened.

What I built

A model that scores every order at purchase time for the risk it misses its promised date, rolls that risk up per seller, and explains each score with SHAP. It uses a leakage-safe time-based split, a hand-built temporal stacking ensemble and calibrated probabilities.

Engineering highlights

A FastAPI service and a Streamlit dashboard run as separate Docker containers on Render. CI lints and runs the test suite on every push, including tests that fail the build if data leaks between training and test sets. A RAG chat answers questions over the model's own predictions.

What went wrong

The first two versions predicted seller risk directly. One turned out to be a busy-seller detector; the next scored no better than a coin flip. Measuring why led to predicting orders instead. Still open: one feature on its own beats the full model, and the README says so.
